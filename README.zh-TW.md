# BA 尋寶助手

[简体中文](README.md) | 繁體中文 | [日本語](README.ja.md) | [English](README.en.md)

蔚藍檔案 Windows 版尋寶助手，幫助你更快、更舒適地尋寶。

它會根據目前棋盤情況和剩餘物品，計算各格的命中機率，並以遮罩方式覆蓋在遊戲畫面上。

## 主要功能

- **機率顯示**：在遊戲棋盤上顯示各格的命中機率。
- **物品占格標記**：根據已翻出的物品片段確認完整占格，以金色邊框標記，並從剩餘機率計算中排除。
- **已確認物品追蹤**：同一輪內繼續翻開占格中的方格時，更新已確認物品的觀察紀錄。
- **手動與自動更新**：翻格後可手動更新，也可開啟自動模式，隨棋盤變化更新結果。
- **最高機率高亮**：開啟「突出最高」後，強調命中機率最高的格子。
- **手動校正**：可修正辨識錯誤的格子狀態、物品尺寸和剩餘數量。

## 下載

前往 [GitHub Releases](https://github.com/RenaKana/ba-treasure-overlay/releases/latest) 下載 Windows 64 位元壓縮檔，解壓縮後執行 `ba-treasure-overlay.exe`。更新時請先關閉舊版助手。

## 使用方法

適用於 **Windows 10 / 11（64 位元）**。執行所需元件及常見問題請參閱[詳細使用說明](app/docs/desktop.md)。

1. 在遊戲中開啟尋寶棋盤，執行 `ba-treasure-overlay.exe`。
2. 在助手中選擇遊戲視窗，點擊連線。
3. 切回遊戲，點擊棋盤旁的更新按鈕，查看機率提示。
4. 每次翻格後重新更新；開啟自動模式後，結果會自動更新。

若方塊外觀無法辨識，點選「選擇樣本」，在 45 格中為每種仍未翻開的外觀選一格，再儲存。取消選擇或儲存失敗時，會保留原有樣本。

儲存的樣本會在本機跨輪次和重新啟動後保留。更換活動或辨識異常時，請檢查畫面並手動更新樣本；清除樣本後會恢復自動辨識。

可在助手視窗頂部切換介面語言並調整介面縮放倍率。縮放設定會保存，且只影響助手控制視窗，不會改變遊戲棋盤上的遮罩座標。

機率僅供參考，不保證每次命中。局部露出的物品在完整占格確認後會標出範圍，並從剩餘機率計算中排除；畫面無法辨識或占格仍有歧義時，助手會暫停推薦。辨識結果與實際畫面不符時，可手動校正後重新更新。畫面辨識和機率計算均在本機完成，助手不會自動翻格。

## 客戶端相容性

| 遊戲環境 | 支援情況 |
| --- | --- |
| 國服 · MuMu 模擬器 | 已進行遊戲內測試，並檢查不同視窗大小下的辨識情況 |
| 國際服 · Steam PC | 已測試 4K 解析度下的活動，以及 16:9、4:3 遊戲視窗 |
| 日服 · PC 客戶端 | 已確認可以讀取視窗畫面；活動內的辨識和機率顯示尚未驗證 |

不同系統縮放、全螢幕模式及新活動的相容情況可能有所不同。若無法辨識，建議切換至視窗模式再次嘗試，詳見[相容性說明](app/docs/pc-compatibility.md)。
