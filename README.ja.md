# BA宝探しアシスタント

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | 日本語 | [English](README.en.md)

ブルーアーカイブ Windows版の宝探しアシスタントです。宝探しをより早く、快適に進められます。

現在の盤面と残りのアイテムをもとに各マスの的中確率を計算し、ゲーム画面上にオーバーレイで表示します。

## 主な機能

- **確率表示**：ゲーム盤面の各マスに的中確率を表示します。
- **手動・自動更新**：マスを開いた後に手動で更新するほか、自動モードでは盤面の変化に応じて結果を更新します。
- **最高確率の強調表示**：「最高値を強調」を有効にすると、最も的中確率が高いマスを強調します。
- **手動修正**：認識されたマスの状態、アイテムのサイズ、残り数を修正できます。

## 使い方

**64ビット版 Windows 10 / 11** に対応しています。必要なコンポーネントとよくある問題については[詳しい使い方](app/docs/desktop.md)をご覧ください。

1. ゲーム内で宝探しの盤面を開き、`ba-treasure-overlay.exe` を起動します。
2. アシスタントでゲームウィンドウを選び、「接続」をクリックします。
3. ゲームに戻り、盤面の横にある更新ボタンを押して確率を確認します。
4. マスを開くたびに更新します。自動モードを有効にすると、結果が自動で更新されます。

各ラウンドで最初のマスを開く前に接続・更新することをおすすめします。45マスそれぞれの初期状態を記憶し、同じ位置の変化を比較します。途中から接続しても認識を試みますが、新しいイベントのマスの見た目によっては、開始時の画面が必要です。

アシスタントウィンドウ上部で表示言語を切り替え、画面全体の表示倍率を調整できます。表示倍率の設定は保存され、アシスタントウィンドウだけに適用されます。ゲーム盤面上のオーバーレイ座標には影響しません。

確率は参考情報であり、毎回当たることを保証するものではありません。画面を認識できない場合や、アイテムがすべて見えていない場合、アシスタントは推奨を一時停止します。認識結果が実際の盤面と異なる場合は手動で修正してから再度更新してください。画面認識と確率計算はローカルで行われ、アシスタントがマスを自動で開くことはありません。

## クライアントの互換性

| ゲーム環境 | 状況 |
| --- | --- |
| 中国版 · MuMuエミュレーター | ゲーム内でテスト済み。異なるウィンドウサイズでの認識も確認済み |
| グローバル版 · Steam PC | 4K解像度でイベントをテストし、16:9と4:3のゲームウィンドウも確認済み |
| 日本版 · PCクライアント | ウィンドウ画面を取得できることを確認済み。イベント内の認識と確率表示は未検証 |

Windowsの表示スケール、フルスクリーン、新しいイベントでは互換性が異なる場合があります。認識できない場合は、ウィンドウモードに切り替えてお試しください。詳しくは[互換性の説明](app/docs/pc-compatibility.md)をご覧ください。

## 問題の報告

問題を報告する際は、プログラムのバージョン、ゲームクライアント、ゲームの言語、具体的な操作手順をお知らせください。スクリーンショットがあると調査に役立ちます。共有する前に、アカウント名やUIDなどの個人情報を隠してください。
