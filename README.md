# BA 寻宝助手

简体中文 | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [English](README.en.md)

蔚蓝档案 Windows 端寻宝助手，帮你更快、更舒适地寻宝。

它会根据当前棋盘情况和剩余物品计算各个格子的命中概率，并将数字以遮罩形式覆盖在游戏内。

## 主要功能

- **概率显示**：在游戏棋盘上显示各个格子的命中概率。
- **物品占格标记**：从已翻出的物品片段确认完整占格，以金色边框标记，并从剩余概率计算中排除。
- **已确认物品跟踪**：同一轮内继续翻开占格中的方格时，更新已确认物品的观察记录。
- **手动与自动刷新**：支持翻格后手动刷新，也可开启自动模式，随棋盘变化更新结果。
- **最高概率高亮**：开启“突出最高”后，突出显示命中概率最高的格子。
- **手动校正**：可修正识别有误的格子状态、物品尺寸和剩余数量。

## 下载

前往 [GitHub Releases](https://github.com/RenaKana/ba-treasure-overlay/releases/latest) 下载 Windows 64 位压缩包，解压后运行 `ba-treasure-overlay.exe`。更新时请先关闭旧版助手。

## 使用方法

适用于 **Windows 10 / 11（64 位）**。运行所需组件及常见问题见[详细使用说明](app/docs/desktop.md)。

1. 在游戏中打开寻宝棋盘，运行 `ba-treasure-overlay.exe`。
2. 在助手中选择游戏窗口，点击连接。
3. 切回游戏，点击棋盘旁的刷新按钮，查看概率提示。
4. 每次翻格后重新刷新；开启自动模式后，结果会自动更新。

如果方块外观无法识别，点击“选择样本”，在 45 格中为每种仍未翻开的外观选一格，然后保存。取消选择或保存失败时，原有样本会保留。

保存的样本会在本机跨轮次和重启保留。更换活动或识别异常时，请检查画面并手动更新样本；清除样本后，助手会恢复自动识别。

可在助手窗口顶部切换语言并调整界面大小。缩放设置会保存，且只影响助手控制窗口，不会改变游戏棋盘上的遮罩坐标。

概率仅供参考，不保证每次命中。局部露出的物品在完整占格确认后会标出范围，并从剩余概率计算中排除；画面无法识别或占格仍有歧义时，助手会暂停推荐。识别结果与实际画面不符时，可手动校正后重新刷新。画面识别和概率计算均在本地完成，助手不会自动翻格。

## 客户端兼容性

| 游戏环境 | 支持情况 |
| --- | --- |
| 国服 · MuMu 模拟器 | 已进行游戏内测试，并检查过不同窗口大小的识别情况 |
| 国际服 · Steam PC | 已测试4K分辨率下的活动及 16:9、4:3 窗口； |
| 日服 · PC 客户端 | 已确认可以读取窗口画面，活动内的识别和概率显示尚未验证 |

不同系统缩放、全屏模式及新活动的兼容情况可能有所不同。若出现无法识别的问题，建议切换至窗口模式再次尝试，详见[兼容性说明](app/docs/pc-compatibility.md)。
